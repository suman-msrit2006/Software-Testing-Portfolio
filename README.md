## Project Title
Food Ordering and Delivery Application

## Objectives
- To understand the modules and functionalities of a food ordering and delivery application
- To prepare a test plan for the selected application
- To design test cases using suitable testing techniques such as equivalence partitioning, boundary value analysis, decision tables and state transition testing
- To execute test cases and record actual results
- To identify and document defects
- To prepare a test execution summary report
- To implement one additional testing activity using a tool such as Selenium, Postman, JUnit or mutation testing

## Project Description
This portfolio documents the testing of a Food Ordering and Delivery Application. The application allows users to register and log in, search for restaurants, browse menus, add items to a cart, place orders, make payments and track deliveries. The testing activities cover the main modules of the application, and all deliverables, including the test plan, test cases, execution results, defect reports, automation scripts, test reports and screenshots, are maintained in this repository.

## Modules Tested
- User registration and login
- Restaurant search and menu browsing
- Cart management
- Order placement and payment
- Order tracking and delivery

## Testing Techniques Used
- Equivalence Partitioning
- Boundary Value Analysis
- Decision Table Testing
- State Transition Testing
