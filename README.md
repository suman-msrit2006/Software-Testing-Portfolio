## Objectives
- To understand the modules and functionalities of a food ordering application
- To prepare a test plan for the selected application
- To design test cases using suitable testing techniques such as equivalence partitioning, boundary value analysis, decision tables and state transition testing
- To execute test cases and record actual results
- To identify and document defects
- To prepare a test execution summary report
- To implement one additional testing activity using Postman for API testing

## Project Description
This portfolio documents the testing of a Food Ordering and Delivery Application (BlissBite). The application lets users register and log in, browse the menu by category, search for food items, choose a portion size and quantity, add items to a cart, place orders and view their order history. The testing activities cover these modules, and all deliverables, including the test plan, test cases, execution results, defect reports, API test documentation, the test summary and screenshots, are maintained in this repository.

## Modules Tested
- Signup and login
- Menu browsing and search
- Cart management (portion size, quantity, remove, total)
- Order placement
- Order history (My Orders)

## Out of Scope
- Payment gateway (not available in the application)
- Admin panel (not available in the application)
- Delivery tracking (not available in the application)
- Performance and security testing

## Testing Techniques Used
- Equivalence Partitioning
- Boundary Value Analysis
- Decision Table Testing
- State Transition Testing
